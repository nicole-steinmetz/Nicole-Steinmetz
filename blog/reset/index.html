Reset: a daily training plan I built because I needed one

NNicole Steinmetz · Web designer and developer
RESET
The problem The build Hosting What I learned

The problem

I’m a website designer, so I spend my days hunched over a screen, and I have tech neck to show for it. In Perth I train at the gym with friends and follow their schedule. When I’m away from them, I struggle to stay motivated without a plan.

I’d found a problem, so I built the solution.

The build

I started by collecting app designs I love on Mobbin, then turned them into a mockup. I took that into Emergent and built the first draft there.

Reset is a quiet daily plan: a short “Reset” version for busy days that still keeps the streak, timers on each exercise, and a place to log my weights.

Hosting

I bought the domain through Spaceship. Emergent gets expensive once an app gets a lot of traffic, so I moved Reset to Cloudflare.

See Reset live

What I learned

Building an app is much easier now. I made Reset with Emergent, and the screens came together fast.

But how an app looks isn’t the hard part. The hard part is how the information inside it fits together.

Think of Lego. A flat house is easy to build. A model where moving one piece changes five others is much harder, even if both look finished on the shelf.

Reset is the flat house. It’s a list of exercises, a timer and a place to log my weights, so it was simple to build. A hotel booking system is the tricky model. Rooms, dates, guests and bookings all have to match up, and if one changes, the rest must change too.

The question I ask

Not “can it build this screen?” but “does it still keep working when I change a rule?”
