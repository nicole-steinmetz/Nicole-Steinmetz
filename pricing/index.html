There isn’t one best platform — there’s the one that fits how your business actually works. This page walks through the five I build on, what each one is genuinely good at, and which is likely to suit you. Once you know where you land, I’ll send you the pricing for that platform.

The short version

Most of this decision comes down to three questions.

Do you need to sell products online? That’s Shopify.
Do you want to log in and change things yourself? That’s Squarespace.
Does the site need to do more than a template allows? That’s a custom build — Cloudflare, Netlify or Vercel underneath.

Know which of those three you are? Jump to that profile below. If you don’t, the profiles are written to make it obvious.

Platform — Cloudflare

The infrastructure behind a custom build

Cloudflare is the network a hand-built site runs on — domain, hosting and delivery in one account you own, built to handle real traffic without extra setup.

See Cloudflare pricing

Worth knowing

This is infrastructure, not a client-run platform — someone has to own the account and the ongoing decisions. Moving DNS here can interrupt email if MX records aren’t copied across first — a one-time step, and no risk when it’s handled properly at launch.

Fast wherever they are

Served from the edge, close to every visitor — not from one data centre on the other side of the world.

Security built in

DDoS protection and SSL come with the platform, not as something to configure and hope for the best.

Platform — Shopify

The commerce engine underneath

Once selling is the job, Shopify runs the parts that matter most — checkout, inventory, fulfilment — so the build can focus on how it looks and feels.

See Shopify pricing

Worth knowing

Shopify is a retail operating platform, not a finished storefront — budget for apps as needs grow, and for Shopify’s own transaction fee if payments run through anything other than Shopify Payments.

Checkout that just works

A native, trusted checkout customers already recognise — one less reason to abandon a cart.

The commerce stack, already there

Inventory, shipping, discounts and payments are built in from day one, not bolted on later.

Platform — Squarespace

Built for hands-on control

Squarespace keeps editing in reach after launch — content, pages, pricing, all from the same screen the site was built in. Built by a Squarespace Platinum Expert (Top 1%), so the setup holds up long after handover.

See Squarespace pricing

Worth knowing

Squarespace buys speed and simple day-to-day ownership — it’s not the cheapest route if the business later needs it to behave like Shopify, a CRM or a custom app.

No developer on speed dial

Swap a photo, add a page, update a price — from the same screen the site was built in.

Design and hosting in one place

Templates, domain, hosting and editing all live under one login — nothing else to manage.

Platform — Netlify

A deploy pipeline for custom code

Netlify runs the other kind of custom build — lean hosting with a workflow built around fast, git-based deploys, so changes go out clean without the overhead of managing servers.

See Netlify pricing

Worth knowing

Netlify is excellent at publishing a custom site reliably — it isn’t a full backend or a fixed-price hosting bill. Like Cloudflare, moving DNS here can interrupt email if records aren’t copied across first.

Deploy without the drama

Every update goes out through the same clean pipeline — previewable before it ever touches the live site.

Built for the modern web

Plays well with the frameworks and tools a genuinely custom site is built from.
