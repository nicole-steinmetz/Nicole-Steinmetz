8 — Vercel hosting

Billed by Vercel

Hosting is billed by Vercel directly, in USD, and set up in your business’s name with access for me. Vercel’s free plan is for personal, non-commercial use only, so business sites need Pro: US$20/month, which includes one deploying user and US$20 of monthly usage. Each extra deploying user is US$20/month (view-only access is free), so with you as owner and me deploying, expect about US$40/month. Usage beyond the included amount is billed on top — I’ll set a spending alert at launch.
